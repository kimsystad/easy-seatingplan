# Easy Seatingplan

Nettlesarapp for sceneoppsett til brassband. Opne `index.html` direkte i ein nettlesar. Ingen installasjon, byggesteg eller nettilkopling er nødvendig.

## Funksjonar

- Hesteskooppsett med 26 messingplassar, fem solokornettar og doble stolar for bassar, kornettbakrekke og trombonar.
- Slagverksymbol med flytting og endring av storleik.
- Stolar, notestativ og slagverksinstrument med speleplass vender seg automatisk mot dirigenten. Namna held seg vassrette.
- Fire pauker i boge med paukestol og storleiksmerking.
- Eksport til PDF og sjølvstendig HTML.
- Automatisk lagring i nettlesaren. Prosjekt kan lastast ned og opnast som JSON.

## Bruk

Vel standardoppsettet, eller start med tom scene. Dra elementa på plass. Trykk på eit element for å endre namn eller stoltype. Dra i det grøne hjørnehandtaket for å endre storleiken på slagverk.

Eksportert HTML er eit sceneoppsett for vising. For vidare redigering på ei anna maskin bruker du **Lagre prosjekt** og **Opne prosjekt** i appen.

**Standard brassband i hestesko** erstattar det opne oppsettet. Lagre prosjektet først dersom du vil ta vare på plasseringane.

## Personvern og drift

Appen brukar berre lokal lagring i nettlesaren. Han sender ikkje sceneoppsett til ein server og har ingen eksterne avhengigheiter. Sceneplanen er ikkje målsett.

For GitHub Pages kan `index.html` publiserast frå rota av repositoryet. Ingen serverkode eller konfigurasjon er nødvendig.
